Introduce the team and the one-line idea: we predict where and when EV charging demand occurs using interpretable count models, turn the forecast into a demand-supply gap map, find under-supplied zones with DBSCAN, and check with a queueing simulation what new ports would actually change. Everything is run on real City of Palo Alto session data; every number on these slides comes from code we ran.
