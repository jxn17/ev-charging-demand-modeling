Model: log mu = log(active ports) + x'beta, so every coefficient is a rate per port. No leakage: every lag looks back at least 24 h, so 2019 forecasts are one-day-ahead. All choices were made on the 2018-Q4 validation quarter: the HGB grid (12 configurations), the trend handling (frozen beat extrapolated and none) and the site interactions (both beat either alone). Site x hour covers 06:00-23:00 only, because some site-hours had zero training arrivals and their MLE would diverge. NB2 alpha is found by maximising the profile likelihood; we wrote a sparse IRLS solver that matches statsmodels to about 1e-9.
